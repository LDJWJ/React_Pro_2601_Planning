# 템플릿 탐색 및 상세보기 화면 구현

## 개요
비디오 템플릿을 탐색하고 선택할 수 있는 모바일 앱 화면 2개를 React Native (또는 Flutter/웹)로 구현해주세요.

---

## 화면 1: 템플릿 목록 (TemplateListScreen)

### 구조
4. **템플릿 그리드** (2열, 무한 스크롤)
   - 각 카드 구성:
     - 썸네일 이미지 (16:9 또는 4:5 비율)
     - 좌상단: 사용자 수 아이콘 + "300"
     - 우상단: 좋아요(하트) 버튼
     - 좌하단 오버레이: 재생시간 "⏱ 18초" + 컷 수 "📄 6컷"
   - **카드 클릭 시 → 화면 2로 네비게이션**


## 화면 2: 템플릿 상세 (TemplateDetailScreen)

### 구조
1. **헤더**
   - 좌측: 뒤로가기 화살표 (←)
   - 배경: 투명 또는 어두운 톤

2. **미리보기 영역**
   - 전체 화면 영상/이미지 프리뷰
   - 어두운 배경 (영상 플레이어 자리)

3. **우측 플로팅 정보** (세로 정렬, 아이콘 + 수치)
   - ⏱ 00:10 (영상 길이)
   - 📄 6 (컷/페이지 수)
   - 👥 1.2k (사용자 수)
   - ❤️ 1.2k (좋아요 수) - 탭 가능, 토글
   - 📋 스토리 기획 (클립보드/노트 아이콘) - 탭 시 바텀시트 오픈

4. **하단 정보 영역** (어두운 오버레이)
   - 해시태그: "#맛집  #브이로그" (탭 가능)
   - CTA 버튼 영역:
     - 메인 버튼: "편집 시작하기" (흰색 배경, 검정 텍스트, 라운드)
     - 우측: 저장/북마크 아이콘 버튼

5. **하단 네비게이션 바**
   - "네비게이션 바" 텍스트 또는 실제 탭바

---

## 인터랙션 요구사항
- [ ] 화면 1에서 템플릿 카드 탭 → 화면 2로 전환 (슬라이드 애니메이션)
- [ ] 화면 2 뒤로가기 → 화면 1로 복귀
- [ ] 좋아요 버튼 탭 → 토글 상태 변경 (filled/outlined)
- [ ] "편집 시작하기" 버튼 → 편집 화면 진입 (placeholder alert 가능)

## 스타일 가이드
- 배경: 화면1 = 흰색, 화면2 = 다크 (#1a1a1a)
- 강조색: 파란색 계열 (검색창)
- 카드: 라운드 코너 8-12px, 그림자 subtle
- 폰트: 시스템 폰트, 한글 지원
- 아이콘: Lucide 또는 SF Symbols 스타일


## 화면 3: 스토리 기획 바텀시트 (StoryPlanningBottomSheet)

### 트리거
- 화면 2 우측 플로팅 메뉴의 📋 아이콘 탭 시 바텀시트로 슬라이드 업

### 구조
1. **상단 영상 프리뷰 영역**
   - 영상 플레이어 (우측 정렬, 라운드 코너 8-12px)
     - 자동 재생 (음소거 상태)
     - 탭 시 재생/일시정지 토글
     - 루프 재생
   - 좌측 오버레이 정보:
     - ⏱ 00:10 (영상 길이)
     - 📄 6 (컷 수)

2. **헤더**
   - 드래그 핸들 바 (중앙, 회색 pill 형태)
   - 제목: "스토리 기획" (Bold, 18-20px)
   - 설명: "각 컷에 넣을 장면을 미리 생각해보고 적어보세요." (Gray, 14px)

3. **컷별 입력 리스트** (스크롤 가능)
   - 각 아이템 구성:
     - 좌측: 컷 번호 (1, 2, 3... 원형 또는 숫자)
     - 중앙:
       - Title (입력 필드 또는 텍스트)
       - Description (서브텍스트, gray)
       - 메모 입력 필드: placeholder "메모를 입력하세요"
     - 우측: time (해당 컷 시간)
   - 컷 수만큼 반복 (예: 6컷이면 6개 아이템)
   - **Optional**: 리스트 아이템 탭 시 영상이 해당 컷 타임스탬프로 이동

4. **하단 버튼 영역**
   - 좌측: "취소" (텍스트 버튼, 회색)
   - 우측: "저장하기" (Primary 버튼, 검정 배경, 흰색 텍스트, 라운드)

### 인터랙션
- [ ] 바텀시트 드래그로 닫기 가능
- [ ] 영상 자동 재생 (음소거), 탭으로 재생/일시정지
- [ ] 컷 리스트 아이템 탭 → 영상이 해당 컷 시점으로 seek (Optional)
- [ ] "취소" 탭 → 바텀시트 닫기 (입력 내용 초기화)
- [ ] "저장하기" 탭 → 입력 내용 저장 후 바텀시트 닫기
- [ ] 각 컷 메모 필드 포커스 시 키보드 올라옴
