비디오 템플릿을 탐색하고 선택할 수 있는 모바일 앱 화면 2개를 React Native (또는 Flutter/웹)로 구현해주세요.

## 화면 2: 템플릿 상세 (TemplateDetailScreen)

### 구조
1. **헤더**
   - 좌측: 뒤로가기 화살표 (←)
   - 배경: 투명 또는 어두운 톤

2. **미리보기 영역**
   - 전체 화면 영상/이미지 프리뷰
   - 어두운 배경 (영상 플레이어 자리)

3. **우측 플로팅 정보** (세로 정렬, 아이콘 + 수치)
   - ⏱ 00:10 (영상 길이)
   - 📄 6 (컷/페이지 수)
   - 👥 1.2k (사용자 수)
   - ❤️ 1.2k (좋아요 수) - 탭 가능, 토글
   - 📋 스토리 기획 (클립보드/노트 아이콘) - 탭 시 바텀시트 오픈

4. **하단 정보 영역** (어두운 오버레이)
   - 해시태그: "#맛집  #브이로그" (탭 가능)
   - CTA 버튼 영역:
     - 메인 버튼: "편집 시작하기" (흰색 배경, 검정 텍스트, 라운드)
     - 우측: 저장/북마크 아이콘 버튼

5. **하단 네비게이션 바**
   - "네비게이션 바" 텍스트 또는 실제 탭바

## 인터랙션 요구사항
- [ ] 화면 1에서 템플릿 카드 탭 → 화면 2로 전환 (슬라이드 애니메이션)
- [ ] 화면 2 뒤로가기 → 화면 1로 복귀
- [ ] 좋아요 버튼 탭 → 토글 상태 변경 (filled/outlined)
- [ ] "편집 시작하기" 버튼 → 편집 화면 진입 (placeholder alert 가능)

## 스타일 가이드
- 배경: 화면1 = 흰색, 화면2 = 다크 (#1a1a1a)
- 강조색: 파란색 계열 (검색창)
- 카드: 라운드 코너 8-12px, 그림자 subtle
- 폰트: 시스템 폰트, 한글 지원
- 아이콘: Lucide 또는 SF Symbols 스타일

### 구조 상세

#### 🔒 FIXED 영역 1: 상단 프리뷰 (position: sticky top)
- 뒤로가기 버튼 (←)
- 영상 플레이어 (중앙 정렬, 라운드 코너 8-12px)

  - 탭 시 재생/일시정지 토글
  - 루프 재생
  - **선택된 컷의 타임스탬프 구간 재생**
- 좌측 하단 오버레이:
  - ⏱ 00:10 (영상 길이)
  - 📄 6컷 (컷 수)

#### 🔒 FIXED 영역 2: 세그먼트 프로그레스 바
- 컷 수만큼 세그먼트로 분할 (예: 6컷 → 6등분)
- 각 세그먼트 구성:
  - 기본 상태: 회색 (#E0E0E0)
  - 활성 상태: 검정 (#000000)
  - 세그먼트 간 간격: 2-4px
  - 높이: 4px, 라운드 코너
- **현재 선택된 컷 인덱스까지 활성화 (filled)**
  - 예: 1번 컷 선택 → [■□□□□□]
  - 예: 3번 컷 선택 → [■■■□□□]
  - 예: 5번 컷 선택 → [■■■■■□]
- 세그먼트 탭 시 해당 컷으로 이동 (Optional)

#### 🔒 FIXED 영역 3: 헤더 (position: sticky)

- overflow-y: scroll
- 각 아이템 구성:
  - 좌측: 컷 번호 (1, 2, 3... 원형 배지, 검정 배경 흰색 텍스트)
  - 중앙:
    - Title (Bold, 16px)
    - Description (Gray, 14px)
    - 메모 입력 필드: placeholder "메모를 입력하세요" (선택된 컷만 표시)
  - 우측: time (Gray, 14px, 예: "2초")
- 컷 수만큼 반복 (템플릿 데이터 기반)
- 선택된 아이템: 테두리 강조 (border: 1px solid #000)

#### 🔒 FIXED 영역 4: 하단 버튼 (position: fixed bottom)
- 배경: 흰색 + 상단 그림자 (shadow)

# 비디오 상세 화면 UI 구현 (React Native / React)

## 화면 개요
비디오 콘텐츠 상세 페이지로, 전체 화면 비디오 뷰어와 오버레이 UI 요소들로 구성

## 레이아웃 구조

### 1. 전체 화면 비디오 영역
- 비디오가 화면 전체(100vh, 100vw)를 채우도록 구현
- object-fit: cover 적용
- 중앙에 재생 버튼 (원형, 반투명 배경 + 플레이 아이콘)

### 2. 상단 영역 (오버레이)
- 좌측 상단: 뒤로가기 버튼 (← 화살표, 흰색)
- position: absolute, top: safe-area-inset

### 3. 우측 하단 액션 버튼들 (오버레이)
- position: absolute, right: 16px, bottom: 약 200px
- 세로로 나열된 아이콘 버튼들: (아래는 18초, 6컷, 300명 등은 예제)
  - 시계 아이콘 + "18초"
  - 프레임 아이콘 + "6컷"  
  - 사람들 아이콘 + "300명"
  - 하트 아이콘 + "1.2k"
  - 문서 아이콘 + "기획"
- 각 아이콘: 흰색, 아래에 텍스트 라벨
- 간격: gap 20px

### 4. 하단 영역 (오버레이)
- position: absolute, bottom: safe-area-inset + 20px
- 좌측 정렬, padding: 0 20px

#### 해시태그 영역
- 가로 배치: "#맛집", "#브이로그"
- 스타일: 흰색 텍스트, 폰트 14-16px
- gap: 12px

#### CTA 버튼 영역 (해시태그 아래 16px 간격)
- 가로 배치: flex-direction: row
- "편집 시작하기" 버튼:
  - 배경: 흰색
  - 텍스트: 검정, bold
  - border-radius: 30px (pill shape)
  - padding: 16px 80px
  - flex: 1
- 북마크 버튼:
  - 정사각형, 배경: #333 또는 반투명 어두운 색
  - border-radius: 12px
  - 북마크 아이콘 (흰색)
  - margin-left: 12px

## 제거 항목
- 하단 네비게이션 바 (홈, 탐색, 편집, MY) 완전 제거

## 스타일 가이드
- 전체 배경: 비디오로 채움
- 오버레이 텍스트: 흰색, 필요시 text-shadow 적용하여 가독성 확보
- safe-area 대응 필수

## 기술 스택
- React 또는 React Native
- TypeScript 권장
- 스타일: Tailwind CSS 또는 styled-components
